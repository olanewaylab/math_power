# math_power

Подготовка за кандидатстудентския тест по математика в **Технически
университет – София**, с агент-репетитор, който работи в чат с Claude.

## Какво има тук

| Път | Какво |
|---|---|
| `docs/plan.md` | Календарен план на подготовката (на руски, за родителя) |
| `docs/exam-format.md` | Формат и точкуване на изпита, тегло в бала |
| `docs/syllabus.md` | Конспект по теми с кодове (`A1`, `G6`, …) |
| `docs/tactics.md` | Тактика на изпитния ден |
| `docs/sources.md` | Официални страници и материали |
| `.claude/skills/math-coach/` | Агентът-репетитор |
| `content/diagnostic/` | Диагностичен тест № 1 + ключ (авторски задачи) |
| `content/past-papers/` | Реални варианти от минали години (свалят се ръчно) |
| `content/visuals/` | Интерактивни визуални материали по теми |
| `progress/` | Статус по теми, дневник на грешките, дневник на сесиите |
| `share/` | Пакет за качване в Claude.ai + инструкции за предаване |
| `docs/handoff.md` | Как агентът се предава на ученика (на руски, за родителя) |

## Как се ползва агентът

В чат с Claude, който има достъп до това хранилище:

| Команда | Какво прави |
|---|---|
| `диагностика` | Дава диагностичния тест и оценява резултата |
| `тема A11` | Учебна сесия по тема с този код |
| `решавай` | Режим задачи: без готови отговори, с насочващи въпроси |
| `тест` | Пробен изпит на време, 20 + 10 задачи |
| `грешки` | Работа по грешките от `progress/errors.md` |
| `къде сме` | Отчет спрямо плана и контролните точки |

Работният език на занятията е **български** — както на изпита.

## Визуални обяснения

Агентът обяснява с чертежи, а не само с текст: чертеж на фигурата при всяка
геометрична задача, числова ос при неравенства, графика при функции, единична
окръжност при тригонометрия. За темите, които се връщат често, има интерактивни
страници в `content/visuals/` — например
[единичната окръжност](https://claude.ai/artifact/TzUiuWJezrdQK1RsMibWSi).

## Първи стъпки

1. Свали вариантите от минали години в `content/past-papers/` (виж `docs/sources.md`).
2. Направи диагностичния тест при изпитни условия: без калкулатор, 90 минути.
3. Дай резултата на агента — той попълва `progress/status.md` и настройва плана.

## Статус на данните

Данните за формата на изпита са възстановени от официалните страници на
`priem.tu-sofia.bg` **през търсачка** — сайтът е недостъпен от средата.
Всичко, маркирано с ⚠️, подлежи на потвърждение от официалния източник
преди да се вземе решение по него (дати, конспект, формула на бала).
