# math_power

Math coach — тренажёр/помощник по математике.

> Статус: инициализация репозитория. Технологический стек пока не выбран,
> структура ниже намеренно нейтральная и будет уточнена при старте разработки.

## Структура

```
math_power/
├── docs/     — документация: требования, архитектурные решения
├── src/      — исходный код
├── tests/    — тесты
└── README.md
```

## Ветки

- `main` — основная ветка, стабильное состояние.
- `claude/*` — рабочие ветки для задач; изменения попадают в `main` через pull request.

## Как начать

Стек ещё не зафиксирован. После его выбора сюда добавляются:
установка зависимостей, запуск, запуск тестов и линтеров.
