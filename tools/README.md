# Скриптове

Изискват `pymupdf` (`pip install pymupdf`). Изпълняват се от корена на проекта.

| Скрипт | Какво прави |
|---|---|
| `normalize-papers.py` | Чете датата **от съдържанието** на всеки PDF в `content/past-papers/`, преименува по конвенцията `YYYY-MM-DD[-v2].pdf`, маха дубликати по контролна сума и пренаписва `INDEX.md` |
| `count-topics.py` | Преброява задачите по теми и модули във всички варианти — оттам идват приоритетите в `docs/syllabus.md` |
| `probe-gaps.py` | Търси теми, които липсват в конспекта (граници, производна, статистика, комплексни числа…) |

Стартират се след всяко добавяне на нови варианти:

```
python3 tools/normalize-papers.py
python3 tools/count-topics.py
python3 tools/probe-gaps.py
```

Класификацията в `count-topics.py` е по ключови думи и оставя ~12%
неразпознати. Резултатът е подредба по честота, не точна статистика.
