# Как передать агента ребёнку

Документ для родителя. Проверено 17.09.2026.

## Сначала два ограничения, которые определяют выбор

**1. Claude требует 18+.** Все пользователи Claude.ai должны подтвердить, что им
18 или больше; при признаках того, что аккаунт принадлежит несовершеннолетнему,
Anthropic просит подтвердить возраст и отключает аккаунт. Это не «мелкий шрифт» —
это работающая система, и аккаунт может быть заблокирован.

- Ребёнку **18 или больше** → у него может быть свой аккаунт, работают способы 1 и 2.
- Ребёнку **меньше 18** → своего аккаунта у него быть не должно. Остаётся способ 3:
  вы запускаете занятия со своего аккаунта и находитесь рядом, а ребёнок отдельно
  пользуется материалами, которые не требуют аккаунта вообще (HTML-страницы,
  PDF, распечатанные тесты).

**2. Память между чатами.** Загруженный скилл не хранит файлы между разговорами.
Поэтому прогресс ведётся «на бумаге»: в конце каждой сессии агент выдаёт короткий
отчёт по образцу, ребёнок его сохраняет и приносит на следующую сессию. Автоматически
прогресс пишется только в способе 2.

---

## Способ 1 — загрузить скилл в аккаунт ребёнка *(рекомендуемый, если 18+)*

Самый простой в ежедневном использовании: обычный чат, работает с телефона,
никакого git и терминала.

1. Скачать `share/math-coach-skill.zip` из этого репозитория.
2. В Claude.ai: **Settings → Capabilities** → включить *Code execution and file creation*.
   Без этого скиллы не загружаются.
3. **Customize → Skills** → загрузить zip.
4. Проверить: написать в чате «започваме занимание по математика».
   Агент должен ответить по-болгарски и предложить диагностику.

Загруженный скилл виден только в этом аккаунте, пока его не расшарят.

Плюсы: привычный интерфейс, телефон, ничего лишнего.
Минусы: прогресс — вручную, через отчёт.

## Способ 2 — Claude Code с этим репозиторием *(если нужен автоматический прогресс)*

Ребёнок (или вы) открывает сессию Claude Code с доступом к `olanewaylab/math_power`.
Скилл подхватывается сам из `.claude/skills/`, агент читает `progress/` и сам же
дописывает туда результаты и коммитит.

Плюсы: единственный способ, где статус по темам и дневник ошибок ведутся сами;
видна вся история занятий.
Минусы: интерфейс для разработчиков, подростку менее удобен; нужен доступ к репозиторию.

Разумная комбинация: **ребёнок занимается способом 1, вы раз в неделю открываете
способ 2** и переносите его отчёт в `progress/`. Тогда история копится, а ребёнок
не видит ни git, ни терминала.

## Способ 3 — без аккаунта у ребёнка *(если младше 18)*

Ребёнку достаются материалы, которые работают сами по себе:

- HTML-страницы из `content/visuals/` — открываются двойным щелчком в любом браузере,
  работают офлайн, ничего не требуют. Можно просто переслать файл.
- PDF реальных вариантов из `content/past-papers/` — печатаются и решаются на бумаге.
- Диагностический тест `content/diagnostic/diagnostic-01.md` — распечатать.

А занятия с агентом вы проводите вместе: вы за своим аккаунтом, ребёнок рядом.
Это, кстати, не худший вариант педагогически — первые недели присутствие взрослого
держит режим.

## Чего делать не стоит

**Просто прислать ребёнку `SKILL.md` и попросить вставлять его в чат.** Технически
работает, но: файл надо вставлять каждый раз заново, справочные материалы
(конспект, формат, тактика, диагностика) остаются снаружи, и через неделю ребёнок
перестанет это делать. Скилл загружается один раз — этим он и отличается от
вставленного текста.

## Что проверить в первый день

1. Агент отвечает **по-болгарски** — если отвечает по-русски, скилл не подхватился.
2. На вопрос «дай ми задача по тригонометрия» не выдаёт сразу решение, а спрашивает.
3. В конце сессии выдаёт отчёт по образцу — значит `references/` прочитаны.

Если что-то из этого не так — скилл загружен неправильно или выключено
выполнение кода в настройках.
