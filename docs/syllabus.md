# Конспект — теми, разбити на работни модули

Съставен по стандартната програма по математика за средно училище (VIII–XII клас),
върху която стъпва тестът на ТУ-София. ⚠️ Свери с официалния конспект за годината.

Всяка тема има код (`A1`, `G2`, …). Кодовете се използват в дневника на грешките
и в статуса, за да се вижда кое проседа.

## Модул A — Алгебра и числа

| Код | Тема | Ключови умения |
|---|---|---|
| A1 | Числа, проценти, пропорции | Действия с дроби без калкулатор, процентно изменение, отношения |
| A2 | Алгебрични изрази | Съкратено умножение, разлагане, рационални изрази, ОДЗ |
| A3 | Степени и корени | Рационален степенен показател, освобождаване от ирационалност |
| A4 | Квадратно уравнение | Дискриминанта, формули на Виет, параметрични условия |
| A5 | Уравнения от по-висока степен | Биквадратни, разлагане, полагане |
| A6 | Ирационални уравнения | Повдигане на квадрат + **проверка на корените** |
| A7 | Модул | Уравнения и неравенства с абсолютна стойност |
| A8 | Неравенства | Квадратни, дробни, метод на интервалите |
| A9 | Системи | Линейни и нелинейни системи, симетрични системи |
| A10 | Показателни уравнения и неравенства | Еднаква основа, полагане |
| A11 | Логаритми | Свойства, смяна на основата, ОДЗ, логаритмични уравнения |
| A12 | Текстови задачи | Движение, работа, смеси, проценти |
