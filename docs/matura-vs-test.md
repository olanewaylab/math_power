# Матура (ДЗИ, профилирана подготовка) против теста на ТУ-София

Документ для родителя. Составлен 24.09.2026 по четырём реальным матурам
из `content/matura/` и 34 вариантам ТУ-София из `content/past-papers/`.

## Сначала важное: это матура профильной подготовки

Все четыре присланных файла — **ДЗИ по математика, ПРОФИЛИРАНА ПОДГОТОВКА**.
Это экзамен для тех, у кого математика — профилирующий предмет. Он не
взаимозаменяем с «обычной» школьной математикой и сдаётся как вторая
обязательная матура теми, кто учится в математическом/ИТ профиле.

⚠️ Прежде чем что-либо планировать, нужно знать: **какую вторую обязательную
матуру будет сдавать ребёнок.** Если математика не его профилирующий предмет,
эти четыре варианта — не его экзамен.

## Структура: два разных экзамена

| | Матура ПП | Тест ТУ-София |
|---|---|---|
| Задач | 18 | 30 |
| Часть 1 | 15 задач с выбором (4 варианта) | 20 задач с выбором (5 вариантов) |
| Часть 2 | **3 большие задачи** с пунктами а/б/в | 10 задач с коротким свободным ответом |
| Баллы | задачи 1–5 по 3, 6–15 по 4 = 55; задачи 16–18 по 15 = 45. **Итого 100** | 20 × 1 + 10 × 2 = **40** |
| Время | 90 мин + 150 мин = **4 часа** | не подтверждено |
| Вероятность угадать | 1/4 | 1/5 |
| Частичные баллы | **Да** — за каждый шаг решения по критериям | **Нет** — 0 или 2 |
| Порог | «Среден 3» = 30 из 100 | порога нет, оценка ранжирует |

## Темы: пересечение неполное

Доля вариантов, где тема встречается:

| Тема | Матура (из 4) | ТУ-София (из 34) |
|---|---|---|
| Производная, касательная | **100%** | 12% |
| Векторы | **100%** | 0% |
| Многочлены: деление, нормальный вид | **100%** | 0% |
| Асимптоты | 75% | 0% |
| Экстремумы через производную | 75% | 0% |
| Случайная величина, матожидание, дисперсия | 25% | 0% |
| Системы счисления | 25% | 0% |
| Аналитическая геометрия | 100% | 21% |
| Пределы | 100% | 50% |
| Вероятность | 100% | 97% |
| Тригонометрия | 75% | **100%** |
| Логарифмы | 25% | **100%** |

Читается так: **матура требует матанализа и линейной алгебры, которых в тесте
ТУ нет вообще. Тест ТУ требует логарифмов и тригонометрии в каждом варианте,
а матура их почти не трогает.**

## Вердикт

**Матура ПП объективно тяжелее — но по другой шкале.**

Тяжелее по трём причинам:
1. **Шире программа.** Производная, исследование функции, асимптоты, векторы,
   многочлены, распределения — целый пласт 11–12 класса, которого нет в тесте ТУ.
2. **Тяжелее форма.** 45 из 100 баллов — три большие задачи с полным письменным
   решением, которое проверяется по критериям. В тесте ТУ Часть 2 требует
   обоснованный, но короткий ответ.
3. **Длиннее.** 4 часа против одного теста из 30 коротких задач.

Но при этом **оценивается мягче**:
- Тройка — это 30 баллов из 100. Треть работы.
- Есть частичные баллы: за верный шаг дают очки, даже если ответ не получен.
  В тесте ТУ задача Части 2 либо решена на 2 балла, либо стоит ноль.

Итог одной фразой: **матура труднее по содержанию и объёму, но прощает ошибки;
тест ТУ проще по темам, но не прощает ничего и предназначен не «сдать», а
расставить кандидатов по местам.**

## Что это значит для подготовки

Подготовка **не общая**. Совпадение по темам примерно наполовину, и расходятся
именно дорогие части: у матуры это матанализ, у теста ТУ — логарифмы,
тригонометрия и стереометрия.

| Сценарий | Что делать |
|---|---|
| Математика — профилирующий предмет ребёнка | Матуру он сдаёт в любом случае. Тогда это два экзамена, а не один: базовый блок (алгебра, геометрия, вероятности) общий, но нужны отдельные ветки — матанализ для матуры, логарифмы и тригонометрия для теста ТУ. Оценка за матуру по математике при этом идёт в балл ТУ ⚠️ |
| Математика не профилирующий предмет | Эти матуры не его экзамен. Тест ТУ-София остаётся основным путём, план из `docs/plan.md` работает без изменений |

⚠️ Обе строки опираются на то, что оценка ДЗИ по математике засчитывается в
конкурсный балл ТУ-София (см. `docs/exam-format.md`). Это найдено через поиск,
а не на самом сайте — проверить на калькуляторе конкурсного балла.
