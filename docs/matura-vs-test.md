# Матура по математике против теста ТУ-София

Документ для родителя. Обновлён 24.09.2026 по 9 реальным матурам из
`content/matura/` и 34 вариантам ТУ-София из `content/past-papers/`.

## Две разные матуры — не перепутать

| Тип | Кто сдаёт | Наши файлы |
|---|---|---|
| **ООП — общеобразователна подготовка** | все остальные, в том числе **по желанию** третьим ДЗИ | 4 варианта: 2020, 2021, май и август 2022 |
| **ПП — профилирана подготовка** | те, у кого математика профилирующий предмет | 5 вариантов: 2022–2025 |

**Ребёнку нужна ООП.** Всё, что ниже про сложность, относится к ней.
Разбор ПП оставлен в конце как справка — он оказался не про нас.

## Структура ООП против теста ТУ

| | Матура ООП | Тест ТУ-София |
|---|---|---|
| Часть 1 | 20 задач с выбором из **4** | 20 задач с выбором из **5** |
| Баллы Части 1 | задачи 1–5 по 2 б., 6–20 по 3 б. = **55** | 20 × 1 = **20** |
| Часть 2 | **3 задачи** с пунктами а/б/в, по 15 б. = **45** | **10 задач** с коротким ответом, по 2 б. = **20** |
| Всего | **100 баллов, 4 часа** (90 + 150 мин) | 40 баллов |
| Частичные баллы | **Да** — за каждый шаг по критериям | **Нет** — 0 или 2 |
| Порог | тройка = **30 из 100** | порога нет, экзамен ранжирует |

Старый формат (2020, 2021) назывался «модул 1 / модул 2» и имел ещё
5 коротких задач по 4 балла между тестом и большими задачами. С 2022 года —
структура из таблицы.

## Оценка сложности

**Матура ООП легче для получения хорошей оценки, тест ТУ тяжелее для
получения высокого результата.** Причины — не в темах, а в устройстве:

| Фактор | В чью пользу |
|---|---|
| Выбор из 4 вариантов против 5 | матура легче (угадывание 25% против 20%) |
| Частичные баллы по критериям | **матура заметно легче**: за верный шаг дают очки, даже если ответ не получен |
| Задачи Части 2 разбиты на а/б/в | **матура легче**: пункт «а» подводит к «б», это встроенная подсказка. В тесте ТУ 10 независимых задач без опор |
| Порог тройки 30% | матура легче: сдать можно с третью работы |
| Полное письменное решение на 45 баллов | **тест ТУ легче**: там нужен обоснованный, но короткий ответ |
| 4 часа работы | тест ТУ легче: короче, меньше усталости |
| Назначение экзамена | тест ТУ **тяжелее по замыслу**: он обязан развести кандидатов по местам, поэтому в нём есть заведомо трудный хвост. Матура проверяет усвоение программы |

Вывод для «среднего» ученика: **набрать хорошую оценку на матуре ООП проще,
чем набрать высокий балл на тесте ТУ**, при примерно одинаковых темах.

## Главное следствие: готовиться надо к обоим

Совпадение тем ~90%, а оценка ДЗИ по математике засчитывается в конкурсный
балл ТУ-София ⚠️ (см. `docs/exam-format.md`). Значит матура — это не
дополнительная нагрузка, а вторая попытка получить тот же балл, причём по
более мягким правилам.

Что нужно добавить к плану из `docs/plan.md`, чтобы закрыть и матуру:

| Дельта | Объём |
|---|---|
| **Векторы** (в тесте ТУ их нет вообще) | 3–4 сессии |
| **Аналитическая геометрия** — глубже, чем нужно для ТУ (75% против 21%) | +2 сессии к теме G8 |
| **Навык писать полное решение** на 15 баллов с пунктами а/б/в | тренируется на самих матурах, 1 вариант в 2 недели с февраля |

Что нужно для ТУ и **не** нужно для матуры: **пределы** (50% вариантов ТУ,
0% матур) и стереометрия в полном объёме (100% против 50%).

То есть общая часть — примерно 85% подготовки, а расхождение сводится к
трём темам и одному навыку записи.

## Справка: профильная матура (ПП) — не наш экзамен

18 задач, 100 баллов, 4 часа: 15 задач с выбором (55 б.) + 3 большие (45 б.).
Требует производной, исследования функции, асимптот, векторов, многочленов,
случайных величин — целого пласта, которого нет ни в тесте ТУ, ни в ООП.
Если бы математика была профилирующим предметом, это был бы отдельный
большой проект. Она не профилирующий — файлы оставлены в `content/matura/`
с пометкой `-pp-` просто чтобы не потерялись.
