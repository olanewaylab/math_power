## Част 2 — отговори и опорни стъпки

**21.** `(x²−4)/(x−3) ≥ 0` · код A8
Нули: −2 и 2; полюс: 3. Метод на интервалите →
**`x ∈ [−2; 2] ∪ (3; +∞)`**. Капан: 3 не влиза (дели се на нула), а ±2 влизат.

**22.** `log₃x + log_x3 = 5/2` · код A11
ОДЗ: `x>0`, `x≠1`. Полагане `t = log₃x` → `t + 1/t = 5/2` → `2t²−5t+2=0` →
`t=2` или `t=1/2` → **`x = 9` или `x = √3`**.

**23.** `2sin²x − 3cos x = 0` · код T3
`2(1−cos²x) − 3cos x = 0` → `2cos²x + 3cos x − 2 = 0` → `cos x = 1/2`
(`cos x = −2` отпада) → **`x = ±π/3 + 2kπ`, k ∈ ℤ**.

**24.** Три числа в АП, сбор 15, сбор на квадратите 83 · код F4
`a−d, a, a+d`: `3a=15` → `a=5`; `50+2d²+25=83` → `d=±2` →
**числата са 3, 5, 7**.

**25.** Триъгълник 13, 14, 15 · код G1
Херон: `s=21`, `S=√(21·8·7·6)=√7056=` **84**;
`h = 2S/BC = 168/14 =` **12**.

**26.** Правилна триъгълна призма, основен ръб 6, височина 5 · код G6
`B = (√3/4)·36 = 9√3` → `V = 45√3`; `S_окол = 3·6·5 = 90`.

**27.** Четни четирицифрени числа с различни цифри от 1…7 · код C1
Последната цифра: 2, 4 или 6 → 3 начина. Останалите три позиции от 6 цифри:
`6·5·4 = 120`. Общо **360**.

**28.** `x² − 2(m−1)x + m + 5 = 0`, два различни реални корена · код A4
`D/4 = (m−1)² − (m+5) = m² − 3m − 4 = (m−4)(m+1) > 0` →
**`m < −1` или `m > 4`**.

**29.** Окръжност с център `C(2;−1)` през `A(5;3)` · код G8
`R = √(3²+4²) = 5` → **`(x−2)² + (y+1)² = 25`**.

**30.** Лодка, 30 km по и срещу течението, общо 8 часа, течение 2 km/h · код A12
`30/(v+2) + 30/(v−2) = 8` → `2v² − 15v − 8 = 0` → `v = 8`
(отрицателният корен отпада) → **8 km/h**.
